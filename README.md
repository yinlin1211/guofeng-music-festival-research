## 🚀 使用建议
1. 先读 `05-方案流程/07-筹备时间轴.md` 建立 6 个月倒排的全局感
2. 报批是生死线:精读 `02-报批许可` + 原文 `01-法规文件/国务院令505号`
3. 预算先跑一遍 `05-预算与票务测算`,**先锁政府补贴与招商再开票**
4. 想抄作业:`02-行业SOP与标准/` 里的潍坊音乐节政府采购方案、怀柔音乐节招标文件就是现成的执行需求书
5. 安全细节直接对标国际标准:`04-国际标准ESA-ANSI/ANSI_ES1.9`(人群管理)与 `ANSI_ES1.7`(恶劣天气)是该领域全球最权威的免费文本
