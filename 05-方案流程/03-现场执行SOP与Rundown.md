# 现场执行 SOP 与 Rundown(分钟级)
> 本 SOP 综合真实招标文件中的服务要求(见 `02-行业SOP与标准/` 北京怀柔音乐节招标文件、潍坊音乐节方案)与 ESA Event Safety Guide 的运营章节编写

---

## 一、现场指挥体系

```
总指挥(主办代表)          对讲 CH1 —— 全场决策
 ├── 制作指挥(舞台)       CH2 —— 舞台监督、音响、灯光、LED
 ├── 安保指挥(对接公安)   CH3 —— 安检口、场内巡逻、出入口
 ├── 现场运营(市集/餐饮)  CH4 —— 摊位、志愿者、卫生间、失物
 ├── 医疗官               CH5 —— 医疗点、救护车、伤病处理
 └── 艺人统筹             CH6 —— 艺人接送、候场、彩排
```
- **任何人不得跳过总指挥对外发布信息**(含社交媒体);事故信息统一由总指挥授权发布
- 关键岗位启用"复诵制":收到指令必须复述确认

## 二、Rundown(单日版 13:00–21:30,12–14 组艺人)

| 时间 | 内容 | 备注 |
|---|---|---|
| 08:00 | 全员到场晨会;设备点检(电源/音响/LED/安检门) | 制作指挥牵头 |
| 09:00 | 舞台技术彩排(乐队调音、舞团走位) | 每 20min 一组 |
| 11:30 | 安检口开放准备;志愿者到岗点名 | |
| 12:00 | **开始入场**(人流高峰 12:00–14:00,预计 60% 观众入场) | 安保 CH3 实时报人数 |
| 13:00 | 开场:鼓乐/舞狮暖场 → 主办致辞(≤10min) | 前区预留媒体位 |
| 13:30–15:00 | 腰部节目 ×3(每个 20–25min,间隔 15min) | 间隔期市集互动/抽奖 |
| 15:00–17:00 | 腰部 ×2 + 汉服巡游大秀(30min) | 巡游路线避开前区 |
| 17:00–18:30 | 中坚力量 ×2(每 30min) | 日落黄金档 |
| 18:30–19:00 | 大型国风舞蹈秀/装置点亮仪式(30min) | 无人机/灯光秀(如有) |
| 19:00–20:00 | 头部嘉宾 1(40–50min) | 全场警戒提级 |
| 20:00–21:15 | 头部压轴(60–75min) | 收尾合唱/谢幕设计 |
| 21:15–21:30 | 谢幕合影 → 散场广播 | 分区分流,详见第四节 |

## 三、岗位 SOP 要点(节选)

**安检口(每口 4 人)**
1. 检票:实名验证(身份证+人脸/票务App),一证一人
2. 人身检查:金属探测仪自上而下,重点肩包、腰包
3. 禁带:瓶装液体(现场提供免费饮水)、打火机、无人机、冷焰火、玻璃制品、大型摄影支架
4. 每半小时向 CH3 报进场人数;**排队超 15 分钟立即开备用通道并上报**

**舞台监督**
1. 每组艺人上场前 15/10/5 分钟三次催场确认
2. 转场倒计时 15min 起每 5 分钟报一次 CH2
3. **歌曲间空场 >3min 即上互动**(投屏弹幕/互动口令),防冷场

**场内巡逻**
1. 每 30 分钟按分区报"人流密度 + 异常情况"
2. 发现过激人群(推挤/攀爬护栏)→ 就近 3 人小组处置,即报 CH1/CH3
3. 走失儿童:带至服务中心广播(广播词模板备案)

**艺人统筹**
1. T-30min 候场,T-15min 待场区,伴奏音源双备份(U盘+云端+备用笔电)
2. 艺人离场动线与观众物理隔离(围栏通道)

## 四、散场 SOP(高风险时段)
1. 21:15 广播词:"演出已接近尾声,请观众从 B/C/D 口按指引离场,接送车辆停放于…"(广播词 3 语版预录)
2. **分区放行**:前区→A 口,中区→B 口,市集区→C 口,避免四区同时涌向单口
3. 接驳车:末班车 = 谢幕后 60 分钟;网约车上落客点距出口 ≥300m
4. 保洁连夜清理;次日 12:00 前场地复原移交(合同写明)

## 五、当天物资清单(索引)
对讲机 60–100 台+备用电池 / 安检门 6–10 / 手持探测仪 20–30 / 护栏水马 / 医疗点 AED ≥2 / 救护车 1–2 / 消防器材点位 / 备用发电机 / 广播系统 / 失物招领系统 / 雨衣 5000 份(雨季)
