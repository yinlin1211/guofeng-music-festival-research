# 古风(国风)音乐节 总体方案与筹备全流程
> 规模:3000–5000人 / 单日或双日 / 12–15组艺人
> 本文为总体框架,各专项细见同目录 02–07 号文件
> 编制依据见根目录 SOURCES.md,关键处均标注了参考的真实文件

---

## 一、定位与概念

### 1.1 产品定义
- **名称(示例)**:「某某·山河入梦」国风音乐节
- **类型**:户外大型营业性演出 + 古风市集 + 汉服体验的复合型文旅活动
- **规模**:单日 3000–5000 人(此规模属《大型群众性活动安全管理条例》"大型群众性活动"范畴,需公安机关安全许可)
- **时长**:单日 13:00–21:30(约 8.5 小时,含转场);或双日各一场

### 1.2 内容板块(4+1 结构)
| 板块 | 内容 | 占场地面积参考 |
|---|---|---|
| 主舞台 | 国风歌手、乐队、舞蹈演出 | 观演区 3000–5000㎡ |
| 古风市集 | 汉服、首饰、文创、非遗手作摊位 40–80 个 | 1500–3000㎡ |
| 体验区 | 汉服租赁妆造、投壶射艺、点茶香道、NPC 巡游 | 1000–2000㎡ |
| 餐饮区 | 国风主题餐车/摊位 15–30 个 | 1000㎡ |
| +1 沉浸点 | 大型花灯/竹编装置、无人机或灯光秀收尾 | 视场地 |

### 1.3 选址要求(硬性)
1. 场地需通过**消防验收或临时消防许可**,容纳能力 ≥ 预期人数的 1.5 倍
2. 远离居民区(噪声投诉),有疏散通道 ≥ 2 条、应急车道贯通
3. 有硬化地面或干燥草坪(雨季需评估),电力接入容量 ≥ 400kVA(不足则配发电车)
4. 当地政府(文旅/公安/街道)支持——**政府态度决定审批难度**,优先选有音乐节举办先例的城市(参考:`03-案例研究/案例04` 音乐节下沉二三线趋势;`02-行业SOP与标准/2022潍坊新青年音乐节` 即政府文旅采购项目)

## 二、组织架构与分工

```
主办方(出资质、总协调)
  ├── 制作总监 ──── 舞台/音响/灯光/LED/转播(总包给专业制作公司)
  ├── 节目总监 ──── 艺人邀约、艺人统筹、节目单编排
  ├── 运营总监 ──── 票务、检票、市集、餐饮、志愿者
  ├── 安保总监 ──── 对接公安、安保公司招标、安检、人流监控
  ├── 宣传总监 ──── 全案传播、票务渠道、艺人宣传物料
  └── 行政财务 ──── 合同、报批、保险、结算
```
- **必备资质方**:营业性演出许可证(主办方或票务合作方须持有);无资质则找有资质的演出公司联合主办
- 每条线编制 1 份执行 SOP(岗位手册),现场人手一份对讲机;频道分配见 `03-现场执行SOP`

## 三、艺人邀约(12–15组)

### 3.1 梯队结构(压轴制)
| 梯队 | 组数 | 参考艺人类型 | 单场费用区间(2024–2025行情) |
|---|---|---|---|
| 头部压轴 | 1–2 | 古风头部歌手(银临、河图、双笙等量级) | 40–80 万 |
| 中坚 | 3–4 | 知名古风歌手/国风乐队(等什么君、自得琴社等量级) | 15–40 万 |
| 腰部 | 4–5 | 二次元/古风圈活跃歌手(HITA、伦桑、萧忆情等量级) | 5–15 万 |
| 气氛组 | 3–4 | 汉服舞团、NPC 剧团、民乐演奏组合、本地节目 | 1–5 万 |

> 费用为行业大致区间,须以报价为准。背景依据:`03-案例研究/案例04_每经网2024` 报告艺人出场费半年涨 50%、艺人成本占音乐节总成本约 60%;`案例06` 单场音乐节成本约千万元级(2–3万人规模)。

### 3.2 流程
1. **T-4~5 个月**:锁定 2–3 个头部候选 → 询价(报演出日期、场地、时长)
2. **T-3~4 个月**:签约(艺人合同必备条款:演出时长≥30min、伴奏方式、宣传义务、天气/不可抗力、取消赔付)
3. **T-2 个月**:收集艺人 TECH 卫星图需求(通道、返听、乐器清单)、宣传物料、唱段报审曲目清单
4. **T-1 周**:艺人统筹表(抵达/彩排/住宿/接送),每 2 组艺人配 1 名艺人助理

### 3.3 曲目合规
营业性演出需将**演出节目单报文旅部门审批**(歌词、字幕、背景视频)。二次元/古风圈歌曲也一视同仁,提前收集全部唱段音源报审;现场歌单不得临时更改。

## 四、场地与制作

### 4.1 舞台配置(3000–5000人标准)
- 主舞台 16×12×1.2m(台面),P8–P10 LED 主屏 + 两侧屏
- 音响:双 12 寸线阵主扩 ≥8 只/侧,补声 4–8 只,舞台监听返送 4–8 轨;**额定功率按场峰人数每 500 人 1 万瓦粗估**,请专业制作公司出方案
- 灯光:面光+染色+光束 60–120 台,控台 Grand MA
- 配电:主电缆 + 备用发电车(演出零断电,双路 ATS 切换)
- 依据:`02-行业SOP与标准/文旅部演出安全行业标准_第6、9部分`(舞美装置、舞台幕布安全)、`05-国际标准ESA-ANSI/ANSI_ES1.18-2022_Rigging`(吊挂)、`ANSI_ES1.17`(灯光电气)

### 4.2 场地分区
- 前排 V 区(站票)/ A 区 / B 区 + 市集带;**前排与舞台隔离栏(水马+护栏)≥4m 缓冲带**
- 安检口按 5000 人 15–20 分钟入场流量倒推:6–10 个安检门,手持金属探测仪 20–30 支
- 卫生间:每 500 人 ≥1 组(男女 1:1.5),市集另配移动厕所
- 依据:`05-国际标准ESA-ANSI/ANSI_ES1.9-2026_Crowd_Management`(人群管理)、`ESA_Event_Safety_Guide`(各分项详规)

## 五、票务与招商

### 5.1 票务
- 渠道:大麦/猫眼/纷玩岛 任一主渠道 + 秀动(青年文化向);**须用有资质票务平台,执行实名制**(多地大型演出已强制实名购票+实名人脸/身份证入场)
- 票价(参考 2024–2025 古风/国潮音乐节):早鸟 199–259 / 预售 259–319 / 全价 359–459 / 双日 459–699 / VIP(含专属观演区+礼包)599–899
- 实名制细节:一证一票、退票规则提前公示

### 5.2 招商
- 层级:首席冠名(50–200 万)/ 行业独家(10–50 万)/ 官方指定(3–10 万)/ 市集摊位费(800–3000 元/档/日)
- 政府补贴:**文旅消费补贴、大型演出奖励是重要收入来源**(依据:`02-行业SOP与标准/海口市大型演唱会音乐节奖励实施细则_2024`,按票房规模奖励 30–300 万;多地有类似政策,立项前先谈)

## 六、报批合规(核心环节,详见 02 号文件)
1. 营业性演出审批(文旅局)——演出资质+节目单
2. 大型群众性活动安全许可(公安局)——1000 人以上必办;本规模 3000–5000 人
3. 消防(临时用房/舞台防火)、交通(临时占道/停车)、食品安全(市集)、医疗急救备案
4. 公众责任险(每次事故保额建议 ≥500 万,按当地要求)

## 七、宣传排期
| 时间 | 动作 |
|---|---|
| T-3 月 | 主视觉官宣、阵容悬念海报(每 3–5 天放 1 组艺人) |
| T-2 月 | 全阵容官宣 + 开票(早鸟) |
| T-1.5 月 | 平台种草(抖音/B站/小红书 古风汉服垂类 KOL 30–50 人) |
| T-1 月 | 倒计时物料、交通攻略、联合票务渠道推广 |
| T-2 周 | 出行攻略、天气提醒、检票须知 |
| T-0 | 直播/短视频现场记录,当晚出返图 |
| T+1 周 | 复盘视频、问卷、下一届预售蓄水 |

古风垂类投放重点:B站舞蹈区/音乐区、小红书汉服话题、微博超话;与汉服社团、高校国风社合作分销(票务分佣 5–10%)。

## 八、风险清单(详见 04 号应急预案)
