# 预算与票务测算(3000–5000人 / 单日 / 12–14组艺人)
> 金额为 2024–2025 行情估算(单位:万元),用于立项测算;实际以招标/询价为准
> 数据背景:`03-案例研究/案例04`(艺人费半年涨50%、成本激增)、`案例06`(单场音乐节成本约千万——2万人级规模)、`案例05`(盈利模式);规模对比后按 3000–5000 人测算

---

## 一、成本侧(单日版)

### A. 艺人费(占总成本 45–60%)
| 项 | 估算 |
|---|---|
| 头部压轴 1 组 | 40–80 |
| 中坚 3 组 × 15–40 | 45–120 |
| 腰部 4–5 组 × 5–15 | 25–70 |
| 舞团/民乐/NPC 3–4 组 | 5–15 |
| 艺人差旅住宿(30–50 人次) | 8–15 |
| **小计** | **123–300** |

### B. 制作硬件(占总成本 25–35%)
| 项 | 估算 |
|---|---|
| 舞台搭建+LED+灯光音响(总包) | 60–120 |
| 配电+发电车 | 8–15 |
| 帐篷/市集设施/隔离栏/厕所/垃圾桶 | 15–30 |
| 场地租赁 | 15–60(政府文旅项目常可低租/免租,见潍坊案例) |
| **小计** | **98–225** |

### C. 安保医疗(刚性,不可省)
| 项 | 估算 |
|---|---|
| 安保 100–250 人 × 300–400 元/人/日 | 8–15 |
| 安检设备 + 检票闸机租赁 | 5–10 |
| 医疗驻场(120 车+医护) | 2–4 |
| 保险(公众责任险 500 万+每次事故) | 3–6 |
| **小计** | **18–35** |

### D. 宣传推广
KOL 投放 30–50 人 + 信息流 + 物料 = **20–60**

### E. 报批与杂项
报批差旅、志愿者(食宿保险)、对讲机、票务平台费已计入收入侧扣点、不可预见费 10% = **15–30 + 预备金**

### 总计
| 口径 | 区间 |
|---|---|
| 精简版(政府支持场地+腰部阵容) | **约 280–350 万** |
| 标准版(1 头部+3 中坚) | **约 400–550 万** |
| 加强版(2 头部+大制作) | **约 550–800 万** |

## 二、收入侧

### 1. 票务收入(主力)
| 假设 | 保守 | 中性 | 乐观 |
|---|---|---|---|
| 售票数 | 3000 | 4000 | 4800 |
| 平均单价(含折扣后) | 280 | 300 | 320 |
| 票房 | 84 万 | 120 万 | 154 万 |
| 平台扣点 8–12% + 实名闸机费后 | ~76 | ~108 | ~137 |

> 古风受众画像(18–35 岁、女性占比 60%+、汉服圈渗透高)对 259–399 价位接受度良好;VIP 票(599–899,含前排+礼包+合影抽签)可拉高均价 5–8%。

### 2. 政府补贴/文旅奖励(强烈建议立项前锁定)
- 海口模式:按票房规模一次性奖励(见 `02-行业SOP与标准/海口市大型演唱会音乐节奖励实施细则_2024.pdf`)
- 常见形式:文旅消费专项资金、活动落地补贴、场地免费(政府平台公司场地)、宣传资源置换
- **区间:0–200 万(落地谈判决定,是二三线城市项目能否盈利的分水岭)**

### 3. 商业招商
| 层级 | 数量 | 单价 |
|---|---|---|
| 首席冠名(茶饮/美妆/游戏/汽车) | 1 | 50–150 |
| 行业独家(汉服品牌/相机) | 2–3 | 10–30 |
| 官方指定 | 4–6 | 3–8 |
| **小计** | | **80–250** |

### 4. 市集与衍生
摊位费 40–80 档 × 1000–2500 元 + 自营餐饮/酒水 + 官方周边(汉服联名款) = **10–35**

### 收入总计
| 口径 | 区间 |
|---|---|
| 保守 | 76+0+80+10 = **约 166 万** |
| 中性 | 108+80+150+20 = **约 358 万** |
| 乐观 | 137+200+250+35 = **约 622 万** |

## 三、盈亏判断
- **盈亏平衡点 ≈ 成本口径 400 万**,对应"中性收入"必须凑齐:票务中性 + 招商 150 万 + 补贴 80–150 万
- 前人教训(`案例05`):音乐节"热闹不赚钱"是常态,主要死因 = 艺人费失控 + 招商未落定就开票
- **行动准则:先锁政府补贴意向 + 招商 60% 再开票;艺人费占票房预期 ≤70%**

## 四、现金流排布
| 节点 | 支出 |
|---|---|
| T-4 月 | 艺人定金 30%(36–90 万) |
| T-3 月 | 场地定金、制作定金 |
| T-1.5 月 | 开票(首笔票务回款按平台结算周期 T+7~30 日) |
| T-1 月 | 制作尾款、安保保险 |
| T-0 后 30 日 | 艺人尾款、结算 |
> 备足过桥资金 150–250 万;票务款按平台 T+1/T+30 两种结算模式选择(现金流紧张选 T+1 高扣点)
