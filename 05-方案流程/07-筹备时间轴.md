# 筹备全周期时间轴(T-6月 → T+1月)
> 与 `01-总体方案` 八章一一对应;每周期结束开一次全员复盘会

```
T-6月 ─┬─ 立项:定位/预算/城市/场地踏勘 ×3 选 1
       ├─ 与属地文旅局/公安/街道预沟通(决定项目生死)
       └─ 组建项目组,定组织架构(01-总体方案·二)

T-5月 ─┬─ 艺人 wish list 询价(06-艺人方案)
       ├─ 制作公司招标(舞台/音响/灯光总包)
       └─ 政府补贴/文旅奖励政策对接(05-预算·收入侧2)

T-4月 ─┬─ 头部艺人签约;场租合同
       ├─ 制作方案定稿(4.1 舞台配置)
       └─ 票务平台商务(实名制方案确认)

T-3月 ─┬─ 全阵容签约 → 官宣视觉
       ├─ 营业性演出审批材料准备
       └─ 招商 deck 发售(冠名/独家)

T-2月 ─┬─ 全阵容官宣 + 开早鸟票
       ├─ KOL 投放启动(50–80 位古风/汉服垂类)
       └─ 市集/餐饮招商(40–80 档)

T-45天 ── 提交营业性演出审批(节目单锁定)

T-30天 ── 公安安全许可申请(02-报批·五)

T-20天 ─┬─ 全价票开售;出行攻略发布
        └─ 公安现场勘查配合

T-10天 ─┬─ 安保/志愿者培训(岗位手册)
        ├─ 艺人统筹表定稿
        └─ 应急预案桌面演练

T-7天  ── 领安全许可;天气预警对接;媒体日安排

T-3天  ─┬─ 舞台进场搭建(预留雨备)
        ├─ 安检设备进场调试
        └─ 市集搭棚,验收消防点位

T-1天  ─┬─ 全要素彩排 + 疏散演练
        ├─ 安保交底会(公安参加)
        └─ Rundown 终版下发(CH1–CH6 频道表)

T-0   ─── 演出日(03-现场执行SOP 全程执行)

T+1天 ─── 撤场复原移交;艺人离场送机

T+7天 ─┬─ 财务结算(现金流对账)
        ├─ 安全复盘会(公安列席)
        └─ 舆情/票务客诉闭环

T+30天 ── 复盘报告 + 下届可行性决策
```

## 关键里程碑(红色警戒)
1. **T-4月头部艺人未签约 → 立即降档模板 B**
2. **T-45天节目单未锁定 → 营业性演出审批会顺延,连锁影响安全许可**
3. **T-30天安全许可材料不全 → 当地公安口径可能要求 20 日底线,过期即改期**
4. **T-1.5月招商 <50% → 重算预算,砍制作不加票价**
