# 艺人邀约与统筹方案(10–15组)
> 费用区间为 2024–2025 二级市场行情参考(单位:万元/场),签约价以经纪公司报价与谈判为准
> 行情背景:`03-案例研究/案例04_每经网2024`——头部艺人费半年涨 50%,音乐节成本激增下艺人结构向"1–2 头部 + 多中腰部"演变

---

## 一、选人逻辑(古风受众)

古风音乐节观众 = 国风音乐听众 + 汉服圈 + 二次元古风圈 + 文旅游客。选人覆盖三层:
1. **听歌的人**:有国民度代表作的古风歌手(能合唱的"回忆杀"曲目)
2. **看脸的人**:汉服/国风视觉系艺人(舞台造型即传播物料)
3. **圈子的人**:圈内活跃、自带粉丝组织(后援会包票)的歌手

## 二、推荐阵容模板(12–14 组,按预算选型)

### 模板 A:标准版(总艺人费 150–250 万)
| 梯队 | 类型示例(等量级参考,非指定名单) |
|---|---|
| 头部 ×1 | 古风头部歌手(银临 / 河图 / 双笙 量级) |
| 中坚 ×3 | 国风乐队(自得琴社 量级)、古风热歌女声、国风男声 |
| 腰部 ×5 | 圈内知名歌手(音频怪物 / HITA / 伦桑 / 萧忆情 / 不才 量级) |
| 视觉 ×3–4 | 汉服舞团、民乐演奏组、NPC 剧团、非遗表演(打铁花需单独审批) |

### 模板 B:精简版(总艺人费 80–150 万)
头部 ×1(腰部上位者降本替代)+ 中坚 ×2 + 腰部 ×4 + 视觉 ×3–4

### 模板 C:平台联名版
与 B 站/网易云音乐等平台联合主办,由平台提供独家艺人资源换曝光分成(参考网易云「国风极乐夜」模式,见 `03-案例研究/案例01`)。

## 三、邀约时间线
| 节点 | 动作 |
|---|---|
| T-5 月 | 列 20 人 wish list → 经纪公司询价(报:日期/城市/场地/时长/预算区间) |
| T-4 月 | 头部签约(定金 30–50%);同步开中腰部谈判 |
| T-3 月 | 全阵容签约完成 → 官宣(悬念式放阵容,每 3–5 天 1 组) |
| T-2 月 | 收 TECH RIG(乐器/通道/伴奏格式)、曲目清单(报审用)、宣传物料 |
| T-1 月 | 艺人统筹表(到达/彩排/住宿/离场);差旅机票出票 |
| T-7 日 | 发艺人手册(场地平面、联络表、天气提醒) |

## 四、合同必备条款(前人踩坑点)
1. 演出时长:**头部 ≥60min、中坚 ≥30min、腰部 ≥20min**(写死,迟到/缩水按比例扣款)
2. 伴奏与音源:伴奏带提前 7 天交付,现场双备份
3. 曲目单:签约时锁定,与报批节目单一致;现场不得更换未报审歌曲
4. 宣传义务:官宣海报/视频 ×2、演出前 1 条社交媒体、现场指定机位授权
5. 取消条款:无故取消双倍返还;天气不可抗力改期优先于取消
6. 接待标准:写死(机票舱位/酒店星级/随行人数上限),防止接待费失控
7. 直播/录像权益归属:先谈好(二创传播是古风音乐节的二次流量池)

## 五、艺人统筹现场 SOP
- 每组艺人配 1 名艺人助理(全程一对一);头部加配专车+独立休息室(带独立卫生间)
- 候场顺序与 Rundown 联动:T-30min 候场区、T-15min 侧台、T-5min 备场
- 音源交接:艺人助理→舞台监督→音控台三方签收
- 谢幕设计:全阵容合唱压轴曲(提前排练或用熟悉旋律带唱),是古风节"出圈名场面"的固定做法
